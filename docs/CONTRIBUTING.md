# Contributing to Cohabio

Thank you for contributing to Cohabio!

## Branching Model
- Follow git flow: create feature branches (`feature/your-feature`) off `develop`.
- Merge into `main` only for tagged releases.

## Coding Style
- **Python**: Follow PEP 8 guidelines. Write descriptive docstrings.
- **Flutter**: Follow official Dart guidelines. Use linter standards.
