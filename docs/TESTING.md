# Cohabio Testing Suite Guide

## ⚙️ Backend Tests
FastAPI tests are located in `backend/tests` and run via `pytest`.

### 1. Run Tests:
```bash
cd backend
pytest
```

---

## 📱 Flutter Client Tests
Flutter checks are split into unit tests, widget layouts, and integration drivers.

### 1. Run Flutter Tests:
```bash
cd mobile
flutter test
```
