# Cohabio Product Roadmap

## Phase 1: Authentication, Profiles, Landing Page, Communities [COMPLETED]
- JWT-based authentication & profile onboarding.
- Community listings, feeds, posts, comments, likes.
- Waitlist site form connection.

## Phase 2: Housing Marketplace, Roommate Matching, Chats [IN PROGRESS]
- Complete housing listings upload, maps pins, amenities filters.
- Swiping candidate profiles, compatibility scores.
- Real-time chat.

## Phase 3: Events & Relocation Guides
- Local user get-togethers, RSVP lists.
- Interactive moving checklist, budget calculators.

## Phase 4: Gemini Recommendation Engine
- Conversational search parsing, AI relocation advising.
